# Forumer 0.2.7

Forumer 0.2.7 is a packaging release. The application code is unchanged from 0.2.6. The one functional change is the Delivery module range in `metadata.json`, so that Forumer can be installed from the catalogue.

## What changes

- **Delivery requirement widened from `~0.4.0` to `>=0.3.0`.** The newest stable Delivery module in the official catalogue is 0.3.3. Delivery 0.4.0 exists only as a release candidate (`v0.4.0-rc.1`), so Forumer 0.2.6 could not be installed from a catalogue on a Basecamp that did not already have a locally installed Delivery 0.4.0. Package Manager reported a conflict on the Delivery row.
- **New catalogue address:** `https://apps.bristinborah.com/logos-repo.json`. It replaces the earlier raw GitHub address of the old `forumer-catalog` repository.

## What was checked

- **Delivery 0.3.0**, the version pinned in `flake.nix`: a development build started with `nix run` on macOS arm64, on the `logos.dev` network. A post settled as sent, history was fetched from the `logos.dev` store nodes, and two instances exchanged posts in a private forum.
- **Delivery 0.4.0**: the checks recorded in the 0.2.6 release notes (text, links, and image transfer between two instances on one Mac, on a Basecamp that includes the image provider, Basecamp #514). The code has not changed since.

Forumer's send handling keys each post on whatever `send` returns and reads the first event argument. That is the request id on Delivery 0.3.x and the message hash on Delivery 0.4.x, which is why the same code runs on both.

## Known limits

- **Catalogue install on a stock Basecamp is not yet tested.** The checks above used a development build, not the 0.2.7 package installed through Package Manager on a profile whose only Delivery module is 0.3.x.
- **Images on Delivery 0.3.x are not tested.** Images still need a Basecamp that includes the image provider (Basecamp #514), as in 0.2.6.
- **The range has no upper bound.** A later Delivery release that changes how `send` or its events behave could break Forumer. The `v0.4.0-rc.1` notes describe such changes. Forumer 0.2.7 has been run only on Delivery 0.3.0 and, as 0.2.6, on 0.4.0.
- **Installer integrity check.** Packages built by the standard pipeline contain the icon at both `assets/icon.png` and `variants/<variant>/assets/icon.png`. Basecamp builds that include the integrity check (Basecamp #533, present in pre-release builds and the 0.4.0 branch, not in stable 0.3.1) may reject them. The catalogue packages are not repacked.
- **Unchanged from 0.2.6:** the Windows x86_64 package is built but experimental. The `logos.test` network needs an RLN membership to send, so use `logos.dev`. Image transfer between two different networks is untested.
